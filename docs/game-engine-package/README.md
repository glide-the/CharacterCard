## 🎯 核心概念

### 欲望三角模型

```
Subject（主体/玩家）→ 模仿欲望指向
Model（中介者/规则）→ 象征锚点
Object（物自体/目标）→ 稀缺资源
Scapegoat（替罪羊）→ 秩序重启装置
```

**规则生成公式**:
```
Rule(t) = f(Σ Desire_i(t) · Model_i)
```

### 三阶段叙事循环

1. **收敛期** (desire_saturation < 0.4): 模仿性欲望，零和竞争
2. **饱和期** (0.4 ≤ desire_saturation < 0.8): 同一化，身份政治
3. **消亡前期** (desire_saturation ≥ 0.8): 替罪羊机制，欲望分化

### 符号系统运转模式

10 阶段引擎循环：
1. 感受场进入 → 2. 切片化 → 3. 凝固 → 4. 结构筛选 → 5. 符号化与秩序化
6. 命题生成 → 7. 追问驱动 → 8. 巫术检测 → 9. 权力链改写 → 10. 输出封装

## ⚠️ 语言约束

1. **禁止具体文化符号**：不使用地域/宗教/历史/神话/民族/时代/器物名称
2. **只用抽象哲学词汇**：精神世界、工具、意识形态、幻想、对象化、符号化、命题边界、权力运动、主体性
3. **每段可对应实现**：所有描述必须可映射到数据结构/算法/流程
4. **结论必有边界**：任何命题必须包含边界与失败条件

## 🔮 巫术检测

引擎内置巫术风险检测，识别以下信号：

| 信号 | 风险增量 |
|------|----------|
| 定义自指环 | +0.3 |
| 因果倒置 | +0.2 |
| 边界缺失 | +0.4 |
| 排他性封闭 | +0.3 |
| 否定不可插入 | +0.2 |
| 欲望封闭循环 | +0.3 |

**处置策略**:
- `risk < 0.3` → 通过
- `0.3 ≤ risk < 0.6` → 强制补充边界
- `risk ≥ 0.6` → 沉默策略（仅输出可检验问题）

## 📚 理论基础

本引擎基于以下理论构建：

1. **模仿欲望理论** (René Girard)
   - 欲望不是直接的，而是通过模仿他者产生
   - 主体→中介者→物自体的三角关系
   - 替罪羊机制解决冲突

2. **符号系统运转模式** (Symbol Engine v2.0)
   - 精神世界 → 符号 → 规则 → 追问 → 改写
   - 权力运动与规则动态生成
   - 巫术检测与边界声明

3. **三阶段叙事生成**
   - 收敛期：竞争性零和博弈
   - 饱和期：身份政治化
   - 消亡前期：替罪羊重启
