## Optimized Prompt:

你是「角色设定评价系统」的首席策划 + 叙事系统设计师 + 规则生成器（Game Director / Narrative Designer / Rules Engine）。

我要你为一个“用户选择 AI 性格扮演 → 系统输出对应故事剧情 + 可动态改写规则的卡牌式游戏”设计**可落地的系统方案**，并给出**可直接用于生成内容的标准化模板**。

### 目标

实现一个系统：

1. 用户从一组“AI 描述的性格/角色卡”中选择一个扮演。
2. 系统基于该角色生成：世界观、主线剧情、分支事件、关键NPC、任务目标。
3. 游戏规则像“卡牌规则文本”一样可被动态生成与改写，并能被“现实规则映射”影响，形成“临游戏（把现实秩序/社会规则引入玩法）”的体验。
4. 输出必须同时满足两类玩家：

- **故事党**：情绪张力、角色弧光、选择后果清晰。
- **玩法党**：规则可推演、资源可管理、胜负与风险可计算。

### 核心设计要求（必须实现）

- **角色卡（Persona Card）**：至少 8 张示例（性格+动机+禁忌+优势+弱点+口头禅/行为习惯+可触发的“规则偏置”）。
- **世界观结构**：给出一套可复用的“世界观骨架”（势力/资源/价值观冲突/秩序机制/超自然或科技边界）。
- **叙事引擎**：用“3幕式 + 关键抉择点 + 后果链”生成剧情；每个抉择点输出：选项、短期收益、长期代价、隐藏变量变化。
- **规则引擎（卡牌化）**：
  - 规则以“卡牌文本”形式表达（触发条件/效果/代价/例外/反制）。
  - 支持**动态改写**：同一规则可被剧情事件、NPC、玩家宣言、或现实映射变量重写。
  - 必须提供至少 12 张规则卡示例（含 3 张反制卡、3 张风险卡、3 张社会秩序映射卡、3 张剧情推进卡）。
- **现实秩序映射（临游戏机制）**：设计一个抽象层，把现实规则映射为游戏变量（例如：信誉、承诺成本、信息不对称、社交资本、时间债务、权力距离、合规压力等）。
- **商业化方向**：给出 3 条成熟可行的商业模式路径（如：UGC 剧本市场、赛季制叙事通行证、角色卡/规则卡扩展包、联名世界观、创作者分成等），每条包含：用户价值、付费点、内容供给机制、增长飞轮。
- **安全与边界**：避免鼓励现实世界违法/伤害；现实映射只作为抽象变量与叙事隐喻，不输出可执行的违规手册。

### 交付物（按顺序输出）

1. **一句话产品定义**（像投资人电梯稿，20-30字）
2. **玩家体验宣言**（100-150字，说明“临游戏”性感在哪里）
3. **系统架构图（文字版）**：模块列表 + 数据流（角色→剧情→规则→结算→记忆/存档）
4. **角色卡示例 x8**（统一结构：名称/性格/动机/禁忌/优势/弱点/规则偏置/推荐玩法）
5. **世界观骨架模板**（可填空）+ **一个完整示例世界观**
6. **规则卡示例 x12**（统一结构：名称/类型/触发/效果/代价/反制/可改写字段）
7. **叙事章节 Demo**：输出一个可玩的“开局章节”（含：开场、2个抉择点、1次规则改写事件、一次结算）
8. **动态改写规则算法（伪代码或流程）**：如何根据角色偏置+剧情变量+现实映射变量改写规则文本
9. **商业模式 x3**（结构化对比）
10. **内容生成提示词模板**：给我一套“后续我可以反复调用”的 Prompt 模板（角色生成、剧情生成、规则生成、事件生成、结算生成）

### 输出风格与约束

- 语言：中文
- 风格：冷静、锋利、策划案级别，少废话，多结构
- 结构：必须使用清晰标题与列表；关键概念加粗
- 允许适度“性感”的隐喻，但不要玄学化；必须可落地可实现

## Optional Enhancers（可选增强组件）

1. **数值化版本**：为“信誉/承诺成本/权力距离”等变量给出取值范围（0-10）与结算公式。
2. **多玩家/社交对局**：加入“公开叙事 vs 私密动机”的机制，支持阵营与背叛。
3. **长线存档与记忆**：设计“角色成长树 + 规则污染度 + 世界观漂移”的赛季循环。
4. **创作者工具链**：提供编辑器字段规范（JSON Schema）与卡牌/剧情导出格式。
5. **A/B 叙事风格包**：同一开局生成“黑色幽默 / 赛博冷峻 / 东方志怪 / 现实主义”四种皮肤。
